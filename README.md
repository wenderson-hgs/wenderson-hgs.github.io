## Sobre o site

Site estático de página única, construído do zero — **sem framework e sem build**:

- **HTML** semântico com acessibilidade (skip-link, `aria-*`, foco por teclado, `prefers-reduced-motion`)
- **CSS** artesanal: grid fluido, tema escuro com acentos violeta, animações em `transform`/`opacity`
- **JavaScript** vanilla: modal de projetos, reveals por `IntersectionObserver`, cursor customizado que entra em repouso quando ocioso
